Analyzing disk space was never so simple a super lightweight, fast, secure desktop utility to determine, what takes up the most space on your disks, the information about your drives and autostart entries on Windows. (Pure Python – Only Standard Library No external dependencies) new!

# Features

1. Your browser will automatically adopt the language of your Windows system (German/English).
2. Disk Space: List all drives, percentage, free space, and hardware info: (SSD/HDD, model, bus, health, TRIM status via Power Shell).
3. Startup Analysis: Displays all startup programs from the registry and folders, with automatic detection of orphaned program files (most likely left behind by uninstalled applications).
4. Multithreaded analysis of folders – the fastest and most reliable way to scan folders and drives, ever! With sortable tables, age indicators and the ability to right click and export CSV/text reports.

# Quick Start

To run the tool, use: python PcAnalysev6.6.py

# Features

1. Automatische Spracherkennung: Passt sich beim Start automatisch an die eingestellte Windows-Sprache (Deutsch/ Englisch) an.
2. Drive Overview: Displays all drives, their usage in percentage, free storage, and detailed hardware info (SSD/HDD, model, bus type, status, and TRIM status through Power Shell).
3. Autostart-Analyse: Zeigt alle Autostart-Programme in der Registry und den Autostart-Ordnern an und listet automatisch fehlende Programmdateien auf (z.B. Überbleibsel früherer Deinstallationen).
4. Größte Ordner & Dateien (Scanner):- Ordner-Analyse multithreading zum Maximaltempo und das Blockieren der GUI überhaupt nicht. Mit sortierbare Tabellen, Altersanzeige, Rechtsklick, Export (csv/ text).
